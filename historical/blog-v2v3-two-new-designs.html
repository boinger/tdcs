Two new Open tDCS designs

I think the clever bit was re-purposing the flash memory voltage regulator to power the circuits entirely from USB. Also the electrode interface has been changed to a standard headphone jack. It’ll make it easier to design a case (also, hackers can save money reusing old connectors).

Version 2: A full-featured programmable stimulator

The schematic and incomplete board layout is available in the v2 branch of the Open tTDCS repository. The potential feature set is huge:

  • Powered and programmed via USB
  • Data logging and runtime control via USB
  • Programmable current ramping and switching
  • Precision current and voltage monitoring
  • Auto-trimming of current
  • Battery operation available via Minty Boost or similar

There is a lot of work to complete before this will be usable. Specifically:

  • MSP430 software needs to be written
  • Squeezing the design into a 2 layer board is proving challenging
  • Hobbyists may be deterred by high part count and SMT parts.

In the next week or two I’ll get the board designed and order prototypes.

Version 3: USB powered, Simple Stimulator

I designed this board to output 2mA (trimmable +-10%) to be powered by USB with a minimal part count. It’s easy to use and has the following advantages:

  • It’s cheap, $8.72/ea.
  • It outputs exactly what you probably want, 2mA.
  • It’s easy to use. Simply attach electrodes, then plug into USB port.

While I was developing v2, I started wondering if switching noise from the charge pump would effect the current ripple of the LM334Z. With the giant output capacitor I am not too worried, but this design started as a cheap way to check. As it evolved, I think it’s a good choice for a plug-and-play tDCS solution for those who just want cheap, easy and reliable current delivery for home use.

Schematic and pcb layout are available in the v3 branch of the Open tTDCS repository. I’ve ordered the prototypes and will update with results / scope images.

How to Build

If you want to build the v3, simply zip the files in the gerber directory and upload to your pcb manufacturer of choice (I use oshpark). Order the parts listed in bom.txt. Solder the parts according to the instructions, and you’re good to go.
